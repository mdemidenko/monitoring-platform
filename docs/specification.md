## Введение

### Описание проекта
Monitoring-platform  - это микросервисная система мониторинга соответствия микросервисов политикам развёртывания в нескольких дата-центрах 

### Цели проекта
- Создать сервис, который мониторит на регулярной основе уровень соотвествия микросервисов тем или иным политикам размещения сервисов по дата-центрам, в случае отклонения от заданных условий - отправлять уведомление в выбранный канал связи (в текущей реализации - telegram)

## Технический стек

### Backend
- **Язык**: Go 1.25.3+
- **Архитектура**: Clean Architecture


### Базы данных
- **Основная БД**: PostgreSQL 15+

### Инфраструктура
- **Контейнеризация**: Docker + Docker Compose
- **CI/CD**: GitHub Actions
- **Мониторинг**: Prometheus

## Тестирование

### Стратегия тестирования
- **Юнит-тесты**: Бизнес-логика, доменные сущности (покрытие > 80%)
- **E2E тесты**: Полные сценарии использования API
- **Нагрузочное тестирование**: Проверка производительности
